## Actual paths

No `package.json`, `vercel.json`, `.github/` or CI exists in the repo. **What currently deploys, and from which file, could not be determined from the repo.** The owner must say which host serves it (Vercel dashboard settings are not visible here).

## Persistence

`localStorage['studyverse-data']`: one JSON blob (`this.data`) with level, totalXP, currentLevelXP, streak, tasks, sessions, flashcards, skillPoints, playerClass, unlockedSkills, skillModifiers, playerStats, equipment, raid history, avatar fields, timer fields.

## Question bank (`data/questions.js`), computed by script

- 148 questions (header comment says "150+"). Math 28, Science 27, History 25, Language 24, Biology 22, Other 22.
- Fields: `id, subject, difficulty, text, choices, correctIndex`. Exactly 3 choices each. No `explanation` field. No duplicate IDs, no duplicate choices inside a question.
- `correctIndex` distribution 0/1/2 = 29/86/33: the middle choice is correct 58% of the time, so "always pick B" beats guessing. Worth rebalancing (shuffle choices at seed/serve time).
- Entries to review (not edited): `hist-h-007` (malformed: question asks which empire Alexander conquered Persia "from"; choices are sentences); `other-h-005` (vague, contested choices); `other-m-005` (longest river is contested, Nile vs Amazon); `hist-m-005` (Cold War end date contested); `hist-h-004` (largest extent was under later khans); near-duplicate concepts: `sci-m-009`/`bio-e-003`/`bio-m` photosynthesis, `sci-e-002`/`other-e-007` (H2O), `sci-m-005`/`bio-h-006` (mitochondria), `lang-h-003`/`lang-h-006` (anaphora/epistrophe).
